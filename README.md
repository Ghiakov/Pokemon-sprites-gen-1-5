# Pokémon Sprites — Generations I–V

8,437 sprite files covering 649 base species (National Pokédex 001–649): battle sprites, shiny variants, animated GIFs, menu icons, and overworld sheets. Battle artwork uses the Generation V Black/White style.

## HTML catalog

Extract the entire ZIP and open **catalog.html** in your browser. It works offline: search by Pokémon name or number, filter by generation and sprite category, and click an image to open its original file. The complete HTML, CSS, JavaScript, and catalog data are included in **catalog.html**; no build step or external scripts are required. Keep the sprite folders beside it.
